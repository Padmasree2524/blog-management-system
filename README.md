# Blog Management System

A modern Blog Management System developed using PHP and MySQL as part of a Web Development Internship project. This application provides complete CRUD (Create, Read, Update, Delete) functionality along with a secure user authentication system.

## Project Overview

The Blog Management System enables users to register, log in, and manage blog posts efficiently through a user-friendly interface. The project demonstrates core web development concepts including database connectivity, authentication, session management, and CRUD operations.

## Key Features

* User Registration System
* User Login Authentication
* Create New Blog Posts
* View All Blog Posts
* Edit Existing Posts
* Delete Posts
* MySQL Database Integration
* Clean and Responsive User Interface

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* XAMPP
* Git & GitHub

## Learning Outcomes

Through this project, the following concepts were implemented and practiced:

* Database Design and Management
* PHP-MySQL Connectivity
* User Authentication and Sessions
* CRUD Operations
* Frontend Styling and UI Design
* Version Control using Git and GitHub
